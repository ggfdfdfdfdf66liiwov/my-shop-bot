# 🤖 ربات فروشگاه کانفیگ تلگرام

## ۱. ساخت ربات

1. به [@BotFather](https://t.me/BotFather) پیام بده
2. `/newbot` بزن
3. اسم و یوزرنیم انتخاب کن
4. **TOKEN** رو کپی کن

## ۲. پیدا کردن آیدی عددی خودت

به [@userinfobot](https://t.me/userinfobot) پیام بده — آیدی عددیت رو بهت می‌ده

## ۳. آپلود روی Railway (رایگان)

1. برو [railway.app](https://railway.app) — با GitHub لاگین کن
2. **New Project → Deploy from GitHub**
3. فایل‌های پروژه رو آپلود کن
4. برو **Variables** و این دو تا رو اضافه کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی
   - `ADMIN_ID` = آیدی عددی خودت
5. Deploy کن — تمام! ✅

## ۴. شخصی‌سازی

در `bot.py`:
- **شماره کارت** رو خط ۱۱۱ عوض کن
- **محصولات** رو در `init_db()` (خط ۳۸) تغییر بده
- **یوزرنیم پشتیبانی** رو در تابع `support` عوض کن

## امکانات ربات

| کاربر | ادمین |
|-------|-------|
| مشاهده محصولات | پنل مدیریت `/admin` |
| خرید و ارسال رسید | تأیید / رد سفارش |
| مشاهده سفارشات | ارسال کانفیگ |
| پشتیبانی | آمار درآمد |
